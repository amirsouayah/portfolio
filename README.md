# Portfolio d'Amir Souayah

Site personnel : parcours en page d'accueil, projets dans les onglets.

Un seul fichier `index.html`, sans étape de build. Ouvrez-le dans un navigateur pour le voir.

Le parcours est décrit dans le tableau `JOBS` du script, en bas du fichier. Les durées et le filtre par technologie se calculent à partir de ce tableau.
